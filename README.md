# 🐾 Pokémon Explorer

> A modern web application for discovering and exploring Pokémon data, powered by **Vue 3**, **TypeScript**, and the **PokeAPI**.

---

## 🌟 Key Features
* **Pokémon Catalog:** Browse through a comprehensive list of Pokémon retrieved from the PokeAPI.
* **State Management:** Utilizing **Pinia** for efficient and reactive data handling across components.
* **Type Safety:** Fully implemented with **TypeScript** to ensure robust and maintainable code.
* **Dynamic Routing:** Seamless navigation using **Vue Router**.

## 🛠️ Tech Stack
* **Framework:** [Vue 3](https://vuejs.org/) (Composition API)
* **Language:** [TypeScript](https://www.typescriptlang.org/)
* **State Management:** [Pinia](https://pinia.vuejs.org/)
* **Routing:** [Vue Router](https://router.vuejs.org/)
* **Build Tool:** [Vite](https://vitejs.dev/)
* **API:** [PokeAPI](https://pokeapi.co/)

## 🔄 Project Evolution
This project originally started as a university assignment called **Component-Passenger-of-airline-Project**. 

Due to the unreliability of the original airline API, I made the strategic decision to rework the entire application into a **Pokémon Explorer**. This transition allowed me to:
1.  Maintain the core learning objectives of API integration.
2.  Practice migrating a codebase to a more stable data source.
3.  Enhance the UI/UX while keeping the underlying logic of component communication.

## 🚀 Getting Started

### Installation
1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/your-username/pokemon-explorer-project.git](https://github.com/your-username/pokemon-explorer-project.git)
    cd pokemon-explorer-project
    ```
2.  **Install dependencies:**
    ```bash
    npm install
    ```

### Development & Build
* **Run Development Server:** `npm run dev`
* **Type-check & Build for Production:** `npm run build`
* **Lint Code:** `npm run lint`
